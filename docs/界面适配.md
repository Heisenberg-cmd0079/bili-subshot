# 界面字号与屏幕适配

界面使用逻辑尺寸并跟随 CustomTkinter 的系统 DPI 处理。正文与输入框字号为 16，辅助提示与日志为 14，分区标题为 19。不会为了完整显示一屏内容而缩小控件或文字。

窗口启动时按当前显示器的工作区限制尺寸，为任务栏和标题栏留出空间。Windows 使用当前显示器工作区；其他平台回退到 Tk 提供的屏幕尺寸。设置区域允许纵向滚动，生成按钮和处理日志始终可见。

窗口宽度不足 720 逻辑像素时，Cookies 移到时间区间下方，导出标签移到输入框上方，字幕预览按钮另占一行。扩大窗口后恢复横排，已输入内容和勾选状态不会改变。多显示器移动时由 CustomTkinter 跟随 DPI 更新，布局重新判断可用宽度。

验证方式：

```sh
python tests_ui_layout.py
```

测试通过 CTk 缩放与工作区测试数据模拟 1366×768/100%、1920×1080/125%、1920×1080/150%、2560×1440/175%、3840×2160/200%，检查窗口边界、控件边界、常显日志、字号与窄宽切换。它不会修改操作系统分辨率或读取/写入个人配置。Linux 无显示环境可使用 `xvfb-run -a python tests_ui_layout.py`。

模拟测试不等同于各实体显示器的实测。发布前建议补充 Windows 混合 DPI 多屏拖动、1366×768 笔记本、4K 高 DPI 屏幕的人工核验。
